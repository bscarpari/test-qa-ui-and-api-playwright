## 🎯 About

Automated test suite covering both **UI** and **API** layers of an e-commerce flow, written with Playwright and TypeScript.

The suite runs **in parallel**, publishes an **HTML report**, and executes automatically on every push through **GitHub Actions**.

Originally built as a technical challenge, then extended with CI, parallel execution and commit-time formatting hooks.

**Targets under test**
- UI — [Swag Labs](https://www.saucedemo.com/), a demo e-commerce application
- API — [Reqres](https://reqres.in/), a public REST API for simulation

## 🧪 Coverage

**UI**
- Login with valid credentials, plus invalid-credential scenarios and their error messages
- Cart manipulation — add three products, remove two, assert the remaining items
- Cart badge counter consistency across add/remove operations
- Checkout blocked when required fields are empty, with the expected validation messages

**API**
- `GET /api/users` — status, payload shape, and field-level assertions including email format
- `POST /api/users` — creation returns 201 with the submitted data
- `PUT /api/users/:id` — update reflects the new values
- `DELETE /api/users/999` — non-existent resource returns the expected error
- Response-time thresholds and network-failure handling

**Structure**

```plaintext
tests/
├── api/
│   └── reqres.spec.ts
└── ui/
    └── swaglabs.spec.ts

```

## 💻 Getting started

**Requirements**

| Tool | Version |
|------|---------|
| Node.js | >= 14.x |
| TypeScript | >= 4.x |
| Playwright | >= 1.12.x |

**1. Clone and enter the project**

```bash
git clone https://github.com/bscarpari/test-qa-ui-and-api-playwright.git
cd test-qa-ui-and-api-playwright
```

**2. Install dependencies**

```bash
npm install
```

**3. Install the browser binaries Playwright needs for UI tests**

```bash
npx playwright install
```

**4. Run the tests**

```bash
npm run test:all     # everything
npm run test:ui      # UI only
npm run test:api     # API only
```

**5. Open the HTML report**

```bash
npx playwright show-report
```

**Debugging**

```bash
npm run debug:ui     # Playwright UI mode
npm run debug:all    # full debug mode
```

**Formatting**

```bash
npm run format        # format all files
npm run format:check  # verify only
```
